### Opción 1: Cloudflare Pages
1. Subir este repositorio a GitHub
2. Conectar en Cloudflare Pages
3. Directorio raíz: `thr33-it-solutions/`

### Opción 2: Vercel
1. Subir este repositorio a GitHub
2. Importar en Vercel
3. Framework: "Other"
